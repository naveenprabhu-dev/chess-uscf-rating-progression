# Featured-player photo credits

These portraits back the one-click "featured players" presets on the home page
(see `webapp/presets.py`). Every image is licensed under a Creative Commons
BY-SA license and is used with attribution as the license requires.

Each file was **downloaded from Wikimedia Commons and resized** (longest edge
scaled to ~400 px) for use as a small thumbnail — that resize is the only
modification, noted here per the share-alike terms. No other edits were made.
